# 💬 Intelligent Customer Support Chatbot

A hybrid AI chatbot that combines **transformer-based intent classification**
with a **generative language model fallback**, built for accurate,
context-aware customer support conversations.

## Overview

This project implements a two-tier conversational AI architecture used by
real-world support platforms:

- **Tier 1 — Intent Classification:** User messages are embedded with a
  sentence-transformer (`all-MiniLM-L6-v2`) and classified into one of 11
  business intents (order status, refunds, shipping, complaints, etc.)
  using a logistic regression model. Confidence is calculated as the
  **max of the model's softmax probability and cosine similarity to the
  nearest intent's example embeddings**, which gives well-calibrated
  scores even on tiny training sets.
- **Tier 2 — Generative Fallback:** When confidence is low (the query is
  outside known intents), a `google/flan-t5-base` transformer generates a
  short, free-form response using a compact prompt built from the last
  exchange. A guard checks the output for echoed/degenerate text and
  swaps in a safe canned response if generation fails.

This design keeps responses **fast and reliable** for common queries while
still **gracefully handling open-ended questions** — without ever letting
a generative model hallucinate business-critical policy information.

## Features

- 🎯 Intent classification with calibrated confidence scoring
- 🧠 Generative fallback for out-of-scope queries, with echo/degeneration guard
- 💭 Multi-turn context memory per conversation session
- 🏷️ Entity extraction (order IDs) with slot-filling in responses
- 🚀 FastAPI REST backend with auto-generated docs
- 🖥️ Streamlit chat UI with live intent/confidence display
- 📊 Automated evaluation pipeline with classification report

## Setup

```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
python train.py
```

## Run

```bash
streamlit run app.py        # Demo UI
# or
uvicorn api:app --reload    # REST API + docs at /docs
```

## Evaluation

```bash
python -m src.evaluate
```
Outputs accuracy, per-intent precision/recall/F1, and a confusion matrix
to `models/evaluation_report.txt`.

## Troubleshooting

- **Bot gives low confidence / uses fallback for obvious messages** — retrain
  (`python train.py`); the centroid-based confidence boost needs the model
  freshly trained to build `intent_centroids.joblib`. You can also lower
  `CONFIDENCE_THRESHOLD` in `src/config.py`.
- **Fallback response looks broken or repeats your question** — this should
  no longer happen (see `response_generator.py`'s `_is_degenerate` guard),
  but if you switch to `flan-t5-small` for speed, expect this failure mode
  to reappear more often; `flan-t5-base` is meaningfully more reliable.
- **First run is slow** — the sentence-transformer and FLAN-T5 models
  download from Hugging Face on first use (a few hundred MB total) and are
  cached locally afterward.

## Future Improvements

- Swap logistic regression for a fine-tuned transformer classifier head
- Add Retrieval-Augmented Generation (RAG) over a knowledge base for the
  fallback tier instead of pure generation
- Persist conversation context in Redis for multi-instance deployments
- Add active-learning loop: log low-confidence queries for human review
  and retrain periodically
